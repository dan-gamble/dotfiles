# Write as Dan

1. Read `~/.claude/VOICE_PROFILE.md` in full. Its Step 0 picks the register from the channel and the reader, so follow it before you draft.
2. Draft in that register. The banned patterns in `~/.claude/writing-rules.md` apply on top, along with the profile's exclusions ("just" stays).
3. Hand Dan the draft to send. Don't send it yourself unless he asked you to.
